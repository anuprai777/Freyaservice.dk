# Awesome DESIGN.md

A curated collection of DESIGN.md design system specifications from top tech companies and developer-focused products.

## How to Use

When asked to design UI matching a specific aesthetic or brand:
1. Check the available brand design guidelines in `design-md/<brand>/DESIGN.md`.
2. Available systems include:
   - **AI & Developer Tools**: Cursor, Claude, Cohere, ElevenLabs, Lovable, Raycast, Replicate, Runway, Together AI, Vercel, Warp, xAI, VoltAgent
   - **Top Products & Tech**: Apple, Airbnb, Stripe, Linear, Figma, Framer, GitHub, Supabase, Notion, Spotify, Uber, Webflow, Wise, Zapier
   - **Cloud & Infrastructure**: ClickHouse, HashiCorp, MongoDB, PostHog, Sanity
3. Read the relevant `design-md/<brand>/DESIGN.md` file using `view_file`.
4. Apply the exact design tokens, typography, color palette, spacing ladders, component anatomy, and micro-interactions defined in the DESIGN.md to the project UI.

## File Organization

All design systems reside under:
`.agents/skills/awesome-design-md/design-md/<brand>/DESIGN.md`
